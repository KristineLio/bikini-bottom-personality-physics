# Bikini Bottom: Personality Physics

Interactive hackathon project: drop characters into a scene and let their personality rules determine what happens.

## Core idea

- Same setup = same outcome
- Change one thing = a new chain reaction
- Judge Demo demonstrates the butterfly effect in about 20 seconds
- Director Mode lets the user place characters and props and run the simulation
- Magic Conch is a playful experiment mode

## Development

The current SkyCastle snapshot is being migrated into this private repository so the project can be improved with normal branches and pull requests.

Primary improvement goals:
1. Make the characters and their motivations visible immediately.
2. Make the 20-second Judge Demo the obvious first interaction.
3. Make the butterfly-effect comparison impossible to miss.
4. Keep the simulation deterministic.
5. Preserve Director Mode and Magic Conch while simplifying the UI hierarchy.
